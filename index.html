¿Cómo alquilar?

Pasos para alquilar

  1. El cliente busca la bicicleta que se acomode a sus necesidades.
  2. Informa al encargado y se revisa la bicicleta.
  3. Se pide documento para el alquiler y se hace el cobro.
  4. Se entrega la bicicleta, casco y candado.

Beneficios

  • Mantenimiento constante a nuestras bicicletas.
  • Asistencia en los recorridos, desde el inicio hasta el final.
  • Precios justos, calidad precio.
